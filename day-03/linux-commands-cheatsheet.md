Process Management – ps, top, htop, kill
File System – pwd, ls, mkdir, find, chmod
Networking Troubleshooting – ip addr, ping, curl, ss, nslookup

Command	Purpose
ip addr	--> Display network interfaces and IPs
ip route --> Display routing table
ping google.com --> Test network connectivity
curl -I https://google.com --> Check HTTP response headers
ss -tulnp --> Display listening TCP/UDP sockets
nslookup google.com	--> Check DNS resolution
dig google.com -->	Detailed DNS lookup
traceroute google.com	--> Trace network route
hostname -I	--> Display assigned IP addresses
